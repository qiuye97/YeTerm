# YeTerm 主题配置文件格式说明

本文档描述 YeTerm(macOS 复古 CRT 终端)的主题配置 JSON 格式,可直接交给 AI 按此规格生成主题文件。

## 使用方式

- 把生成的 JSON 存为 `~/Library/Application Support/YeTerm/profiles/<主题名>.json`(文件名 = 主题名 + `.json`),重新打开 YeTerm 设置即出现在「预设 → 我的配置」;或在设置「配置文件」页用「导入…」选择该文件。
- 所有字段均**可选**:缺省字段走默认值,所以只写关心的字段即可。但**做配色主题时请务必写全「色准三参数」**(见下),否则颜色会被引擎的预混色公式轻微掺灰跑色。
- 颜色一律为 `#RRGGBB` 十六进制字符串。
- 数值特效参数除注明外取值范围 0~1,0 = 关闭。

## 给 AI 的生成建议

生成一套"配色方案型"主题(类似 Dracula/Nord)时,推荐骨架:

```json
{
  "name": "主题名",
  "version": 3,
  "crtEffectsEnabled": true,
  "fontColor": "#______",
  "backgroundColor": "#______",
  "ansiColors": ["#__","#__","#__","#__","#__","#__","#__","#__",
                 "#__","#__","#__","#__","#__","#__","#__","#__"],
  "plainTextColor": "#______",
  "plainBackgroundColor": "#______",
  "plainAnsiColors": ["…与 ansiColors 相同的 16 色…"],
  "contrast": 1.0, "saturationColor": 0, "brightness": 0.5, "chromaColor": 1,
  "rasterization": 4, "screenCurvature": 0, "staticNoise": 0, "flickering": 0,
  "jitter": 0, "horizontalSync": 0, "glowingLine": 0.05, "bloom": 0.2, "burnIn": 0.1,
  "rgbShift": 0, "ambientLight": 0.1, "windowOpacity": 1, "margin": 0.15, "frameMargin": 0,
  "fontName": "Menlo", "fontSize": 14
}
```

生成"CRT 复古特效型"主题(类似绿磷光终端)时,在上面基础上:`rasterization` 改 0(扫描线)或 1(像素),`screenCurvature` 0.2~0.5,`bloom` 0.3~0.6,`burnIn` 0.2~0.5,`staticNoise`/`flickering` 0.05~0.12,`frameMargin` 0.1~0.5(出机壳边框),`chromaColor` 调低(0 = 纯单色荧光屏,所有输出染成 fontColor 的颜色)。**抖动类参数请克制**:`jitter` ≤ 0.08、`flickering` ≤ 0.12、`staticNoise` ≤ 0.15,超过会晃眼。

## 色准三参数(重要)

引擎有一步继承自 cool-retro-term 的「预混色」:上屏前把前景/背景色按对比度、饱和度公式掺混。只有以下取值能让 hex 色值**精确原样上屏**:

```json
"contrast": 1.0, "saturationColor": 0, "brightness": 0.5
```

配色方案型主题必写这三个值;CRT 特效型主题可故意偏离(如 `contrast` 0.8)获得"老屏幕泛灰"的味道。

## 字段说明

### 身份

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | String | 主题名(与文件名一致) |
| `version` | Int | 写 `3`(弧度系数语义版本;`2` 为旧档兼容,弧度会偏小) |

### CRT 模式颜色

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `fontColor` | 颜色 | `#ffffff` | 前景/荧光色。默认文字、光标、辉光、单色染色的基色 |
| `backgroundColor` | 颜色 | `#000000` | 背景色 |
| `chromaColor` | 0~1 | 0 | 色彩浓度:`1` = ANSI/真彩原色保留;`0` = 一切输出染成 fontColor 的纯单色荧光;中间值部分去饱和 |
| `contrast` | 0~1 | 0.8 | 对比度(预混色参数,色准写 `1.0`) |
| `saturationColor` | 0~1 | 0 | 饱和度(预混色参数,色准写 `0`) |
| `brightness` | 0~1 | 0.5 | 亮度增益(`0.5` = 中性 1.0 倍,色准写 `0.5`) |
| `ansiColors` | [颜色]×16 | 无(用内置 crterm 调色板) | CRT 模式 ANSI 16 色表,顺序:黑红绿黄蓝品红青白(0-7 普通)+ 同序明亮(8-15)。粗体基础色自动升明亮位(如 `ls` 目录名 bold-blue → 第 12 位)。`chromaColor` < 1 时会被荧光染色 |

### 普通终端模式(CRT 特效关闭时的素净外观)

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `crtEffectsEnabled` | Bool | true | 主题携带的 CRT 开关状态。`false` = 选中即为素净普通终端 |
| `plainTextColor` | 颜色 | `#ffffff` | 普通模式文字色(精确直出,无预混色) |
| `plainBackgroundColor` | 颜色 | `#000000` | 普通模式背景色 |
| `plainAnsiColors` | [颜色]×16 | Terminal.app 默认表 | 普通模式 ANSI 16 色。做完整主题时与 `ansiColors` 写同一张表 |
| `plainBackgroundImage` | String | 无 | 背景图片绝对路径(个人偏好,主题文件一般不写) |
| `plainBackgroundImageMode` | 0-4 | 0 | 背景图特效:0 无/1 毛玻璃/2 像素风/3 暗化/4 黑白胶片 |
| `plainBackgroundBlur` | 0~1 | 0.5 | 毛玻璃模糊强度 |
| `plainBackgroundPixelPalette` | 0-3 | 0 | 像素风调色板:0 PICO-8/1 DB16/2 GameBoy/3 原色 |

> 主题的正确姿势:CRT 与普通两套颜色都写(`fontColor`=`plainTextColor`、`backgroundColor`=`plainBackgroundColor`、两张 ANSI 表相同),这样开关 CRT 只是加/去特效层,配色身份不变。

### CRT 特效

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `rasterization` | 0-4 | 0 | 光栅化:0 扫描线/1 像素网格/2 子像素/4 无(直通)。3 保留勿用 |
| `screenCurvature` | 0~1 | 0 | 屏幕鼓曲弧度(0.3 ≈ 经典 CRT) |
| `bloom` | 0~1 | 0 | 辉光(文字周围柔光) |
| `burnIn` | 0~1 | 0 | 磷光余辉(内容残影消退时长,0.85 ≈ 存储管终端) |
| `glowingLine` | 0~1 | 0 | 移动扫描亮线 |
| `staticNoise` | 0~1 | 0 | 雪花噪点(建议 ≤ 0.15) |
| `flickering` | 0~1 | 0 | 画面闪烁(建议 ≤ 0.12) |
| `horizontalSync` | 0~1 | 0 | 水平失步扭动(建议 ≤ 0.1) |
| `jitter` | 0~1 | 0 | 字符抖动(建议 ≤ 0.08) |
| `rgbShift` | 0~1 | 0 | RGB 色散(彩色边缘错位,0.2+ = 劣质射频线观感) |
| `ambientLight` | 0~1 | 0 | 环境光(屏幕中心微亮 + 机壳照明) |
| `bloomStyle` | 0/1 | 0 | 辉光风格:0 柔雾(能量守恒高斯,原版)/ 1 光晕 halation(加权 max,亮核峰值不衰减,更像玻璃里的光散射)。两种风格下同一个 `bloom` 值的总体亮度已定标一致 |
| `overdrive` | 0~1 | 0 | **白热化**:笔画自身被打得过狠而发白(零半径,只看该像素自己的亮度)。与 `bloom`(把周围照亮)**正交** —— 想要「中心高亮发白、边缘渐变绿」调这个,不必把辉光开到最大。推荐 0.85。⚠️ **白底主题(背景比前景亮)自动禁用** —— 白热化的前提是「亮的是文字」,白底黑字整个反过来,开着只会啃掉笔画边缘把字洗没 |
| `overdriveKnee` | 0~1 | 0.20 | 白热化起点:亮度低于此不发白。0.20 由真 CRT 照片的饱和度曲线定标(与照片均方差 0.035,关闭时 0.376)|
| `bloomShape` | 0/1 | 0 | 光晕形状:0 单层高斯 / 1 **紧核+长尾**(双尺度)。真 CRT 的光晕衰减比指数快、比高斯慢(玻璃多次散射 + 眼内杂散光),单层高斯裙边太胖。两种形状的平均亮度已定标一致 |
| `emissiveModel` | 0/1 | 0 | 发光模型:0 颜料(原版:辉光先砍平再逐通道加,亮处褪色发白)/ 1 自发光(叠加的光不砍,溢出按色相等比压缩,亮处保持磷光色)。**辉光为 0 时两者输出相同** |

#### 「文字发光」两半怎么调(v1.4)

文字发光是**两件互不相干的事**,分开调才调得准:

| | 参数 | 物理含义 | 空间尺度 |
|---|---|---|---|
| 自身发光 | `overdrive` / `overdriveKnee` | 笔画芯被电子束打得过狠 → 磷光体饱和 + 相机/人眼在高亮端掉饱和 ⇒ **发白** | **零**(就地) |
| 照亮周围 | `bloom` / `bloomStyle` | 光在面板玻璃里散射出去 ⇒ 一圈**磷光色**的晕 | 比笔画大得多 |

想要真 CRT 那种「中心高亮发白、边缘渐变绿」:开 `overdrive`(0.85),辉光反而要**调小**(0.3~0.4),
并把 `bloomShape` 设 1(光更贴笔画、远处更干净)。
以前只有 `bloom` 一个旋钮时,必须把它拉到最大才勉强有点发白,结果光晕重得糊成一片 —— 那是一个旋钮干两份活。

抗锯齿笔画的强度本来就从芯到边递减,所以白热化**自动**产生「芯白边绿」的渐变,不需要额外参数。

### 机壳与布局

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `frameMargin` | 0~1 | 0.2 | 机壳边框尺寸;它或弧度 > 0 时出现机壳层(四角暗角/边缘阴影/反射带) |
| `frameEnabled` | Bool | true | 机壳层总开关(个人偏好,主题文件一般不写) |
| `frameColor` | 颜色 | `#ffffff` | 机壳基色 |
| `screenRadius` | 0~1 | 0.2 | 屏幕圆角半径 |
| `frameShininess` | 0~1 | 0.2 | 机壳反光强度 |
| `margin` | 0~1 | 0.5 | 内容四周留白 |
| `windowOpacity` | 0~1 | 1 | 窗口不透明度(映射 0.7~1.0,0.8 ≈ 半透明悬浮窗) |

### 终端速率(随主题走,每个预设可独立配)

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `bitRate` | Int | 0 | **波特率限速**(bps):字符按老串口速率一个个吐出来。0 = 不限速 |

档位:`110 / 300 / 1200 / 2400 / 4800 / 9600 / 14400 / 19200 / 28800 / 33600 / 38400 / 56000 / 224000 / 1500000 / 10000000`
每字节按 8 位算(纯数据位,不含起止位),故 300 bps ≈ 37 字符/秒、9600 bps ≈ 1200 字符/秒。

**它是主题字段,不是全局偏好** —— 切到没写 `bitRate` 的主题会回到不限速,不会残留上一个主题的速率。
所以可以给「VT220」配 19200、给「Commodore 64」配 300,各用各的。
内置预设出厂一律不写(= 不限速),要慢自己调。

积压中按 ⌃C / ⌃\ 立刻吐完;积压超 1 MiB 也自动吐完 —— 限速是观感特效,不是流控,
`cat` 大文件时不该让终端看着像卡死。

### 字体

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `fontName` | String | Menlo | 字体 family 名。任意等宽字体均可(中文/图标全支持) |
| `fontSize` | Double | 14 | 字号 |
| `fontWidth` | 0.5~1.5 | 1 | 字形横向缩放(1.25 ≈ 老机器宽字符) |

内置复古字体可直接引用(无需安装):`Terminus (TTF)`、`ProFontWindows`、`Fixedsys Excelsior 3.01-L2`、`Pet Me`、`Print Char 21`、`Atari Classic`、`PxPlus IBM VGA8`、`PxPlus IBM BIOS`、`C64 Pro Mono`、`Hermit`、`Inconsolata`、`ProggyTinyTT`、`Ark Pixel 12px Mono zh_cn`(方舟像素,中文点阵)。系统必带等宽:`Menlo`、`Monaco`。

### 行为偏好(全局设置,主题文件一般不写)

`blinkingCursor`、`dividerStyle`、`powerOnEffect`、`powerOnSpeed`、`refreshRate`(30/60/120,0=跟随显示器)、`animateInBackground`、`restoreSession`、`visualBell`、`notifyOnBell`、`notifyLongCommand`、`notifyThresholdSeconds`、`pasteProtection`、`bootSelfTest`、`channelSwitchFX`、`inheritCwd`、`scrollbackLines`、`optionAsMeta` —— 这些是使用者的个人偏好,主题里写了会覆盖使用者的设置,除非刻意需要,否则**省略**。

## 完整示例:CRT 特效型主题「琥珀夜航」

```json
{
  "name": "琥珀夜航",
  "version": 3,
  "crtEffectsEnabled": true,
  "fontColor": "#ffb452",
  "backgroundColor": "#0d0800",
  "chromaColor": 0,
  "contrast": 0.85, "saturationColor": 0, "brightness": 0.5,
  "rasterization": 0, "screenCurvature": 0.3,
  "bloom": 0.45, "burnIn": 0.3, "glowingLine": 0.15,
  "staticNoise": 0.08, "flickering": 0.08, "horizontalSync": 0.05,
  "jitter": 0.05, "rgbShift": 0, "ambientLight": 0.25,
  "margin": 0.3, "frameMargin": 0.25, "windowOpacity": 1,
  "fontName": "Terminus (TTF)", "fontSize": 14
}
```

(单色主题 `chromaColor: 0` 时 ANSI 表无视觉意义,可省略;`plain*` 字段省略 = 关 CRT 时用使用者自己的普通模式配色。)
